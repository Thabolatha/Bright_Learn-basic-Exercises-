# Bright_Learn Basic SQL Exercises

## 📘 Overview

This repository contains basic SQL exercises completed as part of my Bright Learn data analytics learning journey. The exercises are designed to strengthen my foundation in SQL, starting from basic queries and progressing into data functions, NULL handling, UNION operations, joins, and CASE statements.

The purpose of this repository is to show my practical understanding of SQL concepts used in data cleaning, transformation, and analysis.

---

## 📂 Exercises Breakdown

### 🟢 Exercise 1: Basic SQL Queries

**Focus:**

- SELECT statements
- Filtering data using WHERE
- Sorting results using ORDER BY
- Selecting specific columns from a table

---

### 🟡 Exercise 2: Aggregations

**Focus:**

- SUM
- COUNT
- AVG
- GROUP BY
- Basic data summarization

---

### 🔵 Exercise 3: Joins

**Focus:**

- INNER JOIN
- Combining multiple tables
- Understanding relationships between datasets
- Retrieving related information from different tables

---

### 🟣 Exercise 4: CASE Statements & Time Analysis

**Focus:**

- Using CASE statements for classification
- Creating new calculated columns
- Categorizing data into groups
- Time-based analysis such as weekday vs weekend

---

### 🟠 Exercise 5: Data Functions

**Focus:**

- Working with SQL built-in functions
- Text/string functions
- Date functions
- Numeric functions
- Cleaning and transforming data values

---

### 🔴 Exercise 6: NULL Functions

**Focus:**

- Identifying NULL values
- Handling missing data
- Using functions such as COALESCE
- Replacing NULL values with meaningful alternatives
- Improving data quality for analysis

---

### ⚫ Exercise 7: UNION

**Focus:**

- Combining results from multiple SELECT statements
- Understanding UNION vs UNION ALL
- Ensuring column alignment when combining datasets
- Creating one combined result set from similar tables or queries

---
